# 抖音适配器接口支持情况

对照 karin `AdapterType` 标准接口（packages/core/src/types/adapter/class.ts），说明抖音 IM 平台的实现情况。

## 已实现

| 接口 | 说明 |
| --- | --- |
| `sendMsg` | 文本 / 图片 / 视频 / 引用回复（HTTP cookie 通道 cmd=100） |
| `recallMsg` | 撤回消息（cmd=702） |
| `getMsg(contact, messageId)` | 从最近历史消息中查找 |
| `getHistoryMsg` | 历史消息分页（cmd=685）：`start` 为 `indexInConversation` 游标或消息 ID（自动定位），返回 ≤start 的 count 条（时间正序） |
| `getFriendList` | cmd=2006 会话列表中的好友 |
| `getStrangerInfo` | cmd=2047 陌生人消息会话 |
| `getGroupList` / `getGroupInfo` | cmd=2006 群会话 |
| `getGroupAvatarUrl` | 群会话头像 |
| `getGroupMemberList` / `getGroupMemberInfo` | cmd=605 群成员 |
| `getCookies` | 账号 cookie 串 |
| `getCredentials` / `getCSRFToken` | cookie + `passport_csrf_token` |
| `setFriendApplyResult` | 好友申请同意 / 拒绝（cmd=2025） |
| `setGroupApplyResult` | 入群申请同意 / 拒绝（cmd=2025） |
| `setGroupName` | 设置群名（cmd=902 `/v1/conversation/set_conversation_core_info`） |

## 部分支持

| 接口 | 差异 |
| --- | --- |
| `getAvatarUrl` | 自身取登录资料（mosaic 占位自动刷新）；他人按 secUid 查 IM user/info（需先有会话可定位 secUid），无法定位时返回空串 |
| `getMsg(messageId)` | 抖音消息 ID 无会话上下文不可定位，需使用 `getMsg(contact, messageId)` |
| `getGroupInfo` | 群信息来自会话列表缓存，`noCache` 参数无效 |

## 未支持（抖音平台无此能力，调用时打印错误日志并抛错）

| 分类 | 接口 |
| --- | --- |
| 好友互动 | `sendLike`（点赞）、`pokeUser`（戳一戳）、`deleteFriend`、`deleteUnidirectionalFriend`、`getUnidirectionalFriendList` |
| 合并转发 / 长消息 | `createResId`、`getForwardMsg`、`sendForwardMsg`、`sendLongMsg` |
| 消息回应 | `setMsgReaction`（抖音消息无表情回应 API） |
| 群管理 | `groupKickMember`、`setGroupAdmin`、`setGroupMute`、`setGroupAllMute`、`setGroupMemberCard`、`setGroupMemberTitle`、`setGroupQuit`、`setGroupRemark`、`setInvitedJoinGroupResult`（邀请入群无独立审批接口） |
| 精华消息 | `getGroupHighlights`、`setGroupHighlights`、`setEssenceMsg`、`deleteEssenceMsg` |
| 群荣誉 / 签到 | `getGroupHonor`、`sendGroupSign` |
| 群文件系统 | `uploadFile`、`uploadGroupFile`、`downloadFile`、`getFileUrl`、`getGroupFileList`、`getGroupFileSystemInfo`、`createGroupFolder`、`delGroupFile`、`delGroupFolder`、`renameGroupFolder`、`moveGroupFile`、`getGroupFileUrl`、`getGroupRootFiles`、`getGroupFilesByFolder` |
| 禁言相关 | `getGroupMuteList`、`getAtAllCount`、`getGroupAtAllRemain` |
| AI 语音 | `getAiCharacters`、`sendAiCharacter`、`sendGroupAiRecord` |
| 资料修改 | `setAvatar`、`setBotInfo`、`setGroupPortrait` |
| 陌生群 | `getNotJoinedGroupInfo` |
| 媒体获取 | `getImage`、`getRecord`、`ocrImage`、`dotOcrImage`、`fetchCustomFace`、`getWordSlices` |
| QQ 专属 | `getRkey`（NapCat rkey 体系）、`getGroupSystemMsg` |

## 说明

- 上述"未支持"接口为 QQ 协议端能力或依赖 QQ 平台特有体系（群文件、禁言、rkey 等），抖音 IM 协议中不存在对应接口。
- 后续如逆向确认抖音存在对应能力（如群公告、表情回应等），可在 `src/core/im` 补协议后接入。
