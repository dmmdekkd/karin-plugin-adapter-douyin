# 项目记忆

## 包管理器（强制）

- 本项目完全使用 **pnpm**，禁止使用 npm / yarn（项目为 pnpm workspace：`pnpm-workspace.yaml` + `pnpm-lock.yaml`，`.npmrc` 也是 pnpm 风格）。
- 安装依赖：`pnpm add <pkg>`；一次性安装：`pnpm install`
- 运行脚本/工具：`pnpm <script>`、`pnpm exec <cmd>`（lint、tsc、build、预览等一律走 pnpm）
- 锁文件：修改依赖后必须更新 `pnpm-lock.yaml`，不提交 npm 相关产物。

## 目标与风格

- 目标是简洁、简短、代码质量高；移除所有兼容旧版本的代码，不保留兼容层。
- 依赖库（douyin.ts 等）一律以 `node_modules` 中实际安装版本为准进行适配重构，按其类型定义与事件系统调整插件代码。
