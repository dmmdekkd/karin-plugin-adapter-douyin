# 移除兼容与简洁化重构计划（第二轮）

## 一、Summary

在上一轮「基于 douyin.ts SDK 完全重构」基础上，进行第二轮精简：

- **移除所有兼容旧版本的痕迹**（兼容登录入口、历史数据回退读取）
- **删除死代码与别名方法**
- **方法/变量去多层嵌套，平铺直叙**，追求简洁、简短、高质量代码

目标产物：全仓无「兼容」「别名」「兜底旧数据」残留，`npx tsc --noEmit` 通过。

## 四、假设与决策

1. **登录方式恒定 qr**：`LoginOpts` 已由 douyin.ts `login()` 内部处理，method 概念彻底删除（用户已确认）。
2. **旧格式数据不再兼容**：若用户升级前存在历史落盘（hash uid / userData 内嵌 name），升级后按新版扁平格式读不到即视为无会话，需重新扫码（用户已确认）。
3. **AdapterBase 抽象方法风险**：本地无法确认 node-karin 抽象方法清单，删别名后若 tsc 报「未实现抽象方法」，只补回报错的那一个（体内 `unsupported(...)`）。
4. **扁平化只动结构不动行为**：不合并/拆分功能，不改写业务语义，保持可读性优先。
5. **不改动**：apps/update、utils/update、store/account、types、api 下其余文件、adapter 下 message/notice/request/convert/autoRead/util（上一轮已稳定）。
